## 구현 기능 목록

**문자열 입력**

- [x] 문자열 입력받기
  - “덧셈할 문자열을 입력해 주세요.”
- [x] 구분자 처리
  - 기본 구분자(쉼표,콜론) 지정
  - 문자열 앞부분에 "//"와 "\n" 사이 커스텀 구분자를 지정했다면 구분자 추가
- [x] 입력값 검증
  - 구분자를 기준으로 문자열 분리
  - [예외] 음수 입력 시
  - [예외] 숫자가 아닌 값 입력 시
  - [예외] 구분자로 시작하거나 끝나는 경우
  - [예외] 구분자가 2자 이상인 경우
  - 예외 경우 "[ERROR]"로 시작하는 메시지와 함께 에러 발생 후 종료

**결과 출력**

- [x] 숫자 합 계산 후 출력
  - 빈 문자열은 0으로 처리 (결과 : 0)
  - 분리한 문자 숫자로 변환
  - 각 숫자 합 계산
  - “결과 : 6” 형식으로 계산 결과 출력
