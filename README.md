## 구현 기능 목록

**문자열 입력** 

- [ ]  문자열 입력받기
- [ ]  기본 구분자(쉼표,콜론) 지정
- [ ]  문자열 앞부분에 "//"와 "\n" 사이 커스텀 구분자를 지정했다면 구분자 추가
- [ ]  빈 문자열은 0으로 처리 (결과 : 0)
- [ ]  [예외] 음수 입력 시
- [ ]  [예외] 숫자가 아닌 값 입력 시
- [ ]  [예외] 구분자로 끝나는 경우
- [ ]  [예외] 구분자가 연속된 경우
- [ ]  예외 경우 "[ERROR]"로 시작하는 메시지와 함께 에러 발생 후 종료

**결과 출력** 

- [ ]  구분자를 기준으로 분리
- [ ]  숫자로 변환
- [ ]  각 숫자 합 계산
- [ ]  “결과 : 6” 형식으로 결과 출력
